# PURSUE — front-end recreation

A responsive educational recreation of the screenshot, built with plain HTML, CSS, and JavaScript. The records and text are sample content, not authentic government records.

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No npm install, build step, server, or API key is required.

## Interactions
- Select records in the carousel, use arrows, or press the keyboard left/right keys.
- Open a record for a larger document preview.
- Export a sample record summary as a `.txt` file.
- Search the sample archive.
- Toggle the official-site information and responsive navigation.
